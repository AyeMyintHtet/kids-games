1. Core Architectural PrinciplesPerformance-First Rendering: Use React.memo for all list items and heavy components. Use useCallback for all functions passed as props to avoid downstream re-renders.The "Rule of Hooks": Business logic must reside in custom hooks (/hooks). JSX should remain purely declarative.The Bridge Bottleneck: Minimize JS-to-Native passes. Use worklets (via react-native-reanimated) for any UI interaction involving movement or layout changes.2. Component Construction (The "No-Jank" Rule)Pressables: Prefer Pressable with android_ripple or RectButton from gesture-handler over TouchableOpacity for a more native feel.Hit Slops: All interactive elements must have a minimum touch target of $44 \times 44$ dp. Use hitSlop={{ top: 10, bottom: 10, left: 10, right: 10 }} for small icons.Images: Strictly use expo-image. Never use the standard Image component. expo-image handles disk caching and memory-efficient decoding natively.Layout: Use Flexbox exclusively. Avoid absolute positioning unless building overlays or floating action buttons.3. High-Performance Stack (Outsourced Intelligence)When generating code, prioritize these libraries over manual implementations:| Category | Recommended Library | Reason || :--- | :--- | :--- || Lists | @shopify/flash-list | Recycles components; $10\times$ faster than FlatList. || State | Zustand | Atomic updates, zero provider-hell, minimal overhead. || Data Fetching | @tanstack/react-query | Automated caching, background synchronization, and loading states. || Animations | react-native-reanimated | Runs on the UI thread (60 FPS guaranteed). || Forms | react-hook-form + zod | Uncontrolled inputs for better performance; type-safe validation. || Navigation | Expo Router | File-based, typed, and deep-link ready by default. |4. Code Quality & DXTypeScript: Strict typing is mandatory. No any. Use interface for component props.Styling: Use StyleSheet.create for static styles. Use NativeWind (Tailwind) for rapid, readable UI development without the CSS-in-JS performance hit.Icons: Use @expo/vector-icons for tree-shakable, lightweight iconography.5.
